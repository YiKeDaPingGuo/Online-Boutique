# OmniAnomaly 模型训练复现指南

## 前置条件

- conda 环境: `omnianomaly` (Python 3.6, TensorFlow 1.15)
- 若没有此环境, 需先安装: `conda create -n omnianomaly python=3.6 && conda activate omnianomaly && pip install tensorflow==1.15.5 numpy==1.18.5 pandas==0.23.4 scikit-learn==0.20.2`

## 获取代码

```bash
git clone https://github.com/tomatosmash/microservices-demo.git
cd microservices-demo/paper_reproduce/omnianomaly_kdd19
```

## 获取数据集

将以下文件放入 `processed/` 目录 (需从组长处获取):
- `boutique_train.pkl` (674 点 × 156 维)
- `boutique_test.pkl` (1653 点 × 156 维)
- `boutique_test_label.pkl` (标签)
- `boutique_dim.txt` (维度数: 156)

## 训练

```bash
conda activate omnianomaly
python main.py
```

## 修改参数

编辑 `main.py` 中 `ExpConfig` 类:
- `z_dim`: 隐变量维度 (当前 8)
- `window_length`: 滑动窗口 (当前 20)
- `max_epoch`: 训练轮数 (当前 100)
- `window_length`: 滑动窗口 (当前 20)
